# CampusConnect — COMSATS University Web Portal

A mini university web portal built with HTML, CSS, and JavaScript for the Web Development Lab.

## Pages
- **Home** — Hero section, quick links, university stats
- **Departments** — 6 academic departments with details
- **Courses** — Course catalog organized by department
- **Student Services** — Library, Financial Aid, Counseling, Career, Health, Sports, IT, Transport
- **Contact** — Contact info + Student Enquiry Form with JS validation

## Tech Stack
- HTML5
- CSS3 (Responsive)
- JavaScript (Vanilla)
